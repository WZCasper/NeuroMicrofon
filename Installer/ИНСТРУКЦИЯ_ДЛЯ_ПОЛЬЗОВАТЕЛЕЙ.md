# Если Windows показывает предупреждение при установке

При запуске `NeuroMicrophone_Setup.exe` Windows может показать синий экран
«Windows защитила ваш компьютер» с кнопкой «Не запускать». Браузер при
скачивании файла может показать похожее предупреждение «Файл может быть
опасен» или «Такой файл обычно не скачивают».

## Почему так происходит

Это предупреждение называется **SmartScreen**, и Windows показывает его
для программ от разработчиков, которые не купили платный сертификат
цифровой подписи (такой сертификат стоит от $100–400 в год и обычно есть
только у крупных компаний). Оно означает не «программа опасна», а
«у Microsoft пока мало сведений об этой программе» — SmartScreen работает
по статистике: чем больше людей скачали и запустили файл без проблем, тем
реже он показывает предупреждение для этого же файла.

## Что делать в Windows (при запуске установщика)

1. На экране «Windows защитила ваш компьютер» нажмите **«Дополнительно»**
   (или «More info»).
2. Появится описание программы и кнопка **«Всё равно запустить»**
   («Run anyway») — нажмите её.
3. Дальше установка пойдёт как обычно.

## Что делать в браузере (при скачивании файла)

- **Microsoft Edge / Chrome**: если появилось предупреждение о файле,
  нажмите на стрелку рядом с загрузкой → **«Сохранить»** / **«Оставить»**
  («Keep») вместо «Удалить».
- Если браузер скачал файл, но потом заблокировал запуск — используйте
  шаги для Windows выше.

## Как убедиться, что файл настоящий

Исходный код NeuroMicrophone полностью открыт в репозитории
`https://github.com/WZCasper/NeuroMicrofon`, а сама сборка `.exe`
происходит автоматически и прозрачно через GitHub Actions — вкладка
**Actions** в этом репозитории показывает точно, из какого кода и когда
был собран конкретный файл. Технически подготовленный пользователь может
собрать программу из исходников самостоятельно и сравнить результат.
