# Пакет виртуального аудиодрайвера (Driver/Package)

Эта папка должна содержать **уже подписанный** пакет драйвера перед сборкой
установщика: `NeuroMicCable.inf`, соответствующий `.sys`, и `.cat`
(каталог подписи).

## Почему нельзя просто сгенерировать эти файлы

Начиная с Windows 10, ядро операционной системы отказывается загружать
драйверы без действительной цифровой подписи (Driver Signature
Enforcement). Это проверяется на уровне ОС при попытке `pnputil
/add-driver ... /install` — никакой код в самом приложении или
установщике не может обойти эту проверку. Поэтому «сгенерировать»
работающий подписанный kernel-mode драйвер без реального процесса
подписи невозможно — это не техническое ограничение данного проекта,
а требование безопасности Windows.

## Два легитимных пути получить пакет

### Вариант A — собрать и подписать пример Microsoft (SYSVAD) самостоятельно

1. Клонируйте `https://github.com/microsoft/Windows-driver-samples` и
   откройте `audio/sysvad` в Visual Studio с установленным Windows
   Driver Kit (WDK).
2. Соберите проект под конфигурацию x64 Release.
3. Получите сертификат подписи кода (EV code signing certificate) у
   доверенного удостоверяющего центра.
4. Пройдите процедуру аттестационной подписи через Microsoft Hardware
   Dev Center (`https://partner.microsoft.com/dashboard/hardware`) —
   это бесплатно для аттестационной подписи, но требует регистрации
   разработчика и упомянутого EV-сертификата.
5. Скачанный после аттестации пакет (.inf/.sys/.cat) поместите в эту папку.

### Вариант B — использовать существующий подписанный редистрибутив

Ряд сторонних поставщиков виртуальных аудиокабелей распространяют уже
подписанные пакеты драйверов на условиях, допускающих встраивание в
установщики третьих лиц. Изучите лицензию конкретного поставщика перед
использованием — условия отличаются.

## Как назвать устройство «NeuroMicrophone Cable»

Имя, под которым устройство появится в Windows, задаётся в самом
`.inf`-файле пакета (секция `[Strings]` / `DeviceName`). Отредактируйте
эту строку в исходниках драйвера ДО его сборки и подписи — после
подписи менять содержимое файлов уже нельзя (подпись станет
недействительной).

## Проверка после установки

`DriverInstaller.IsDriverInstalled()` в приложении ищет устройство
вывода, чьё `FriendlyName` содержит строку `"NeuroMicrophone Cable"` —
убедитесь, что имя в `.inf` совпадает (или обновите константу
`DriverInstaller.VirtualDeviceName` в коде под своё фактическое имя).
