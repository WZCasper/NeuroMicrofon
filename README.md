# NeuroMicrophone

Windows-приложение для обработки микрофона в реальном времени: подавление
шума (RNNoise, с учётом голосовой активности), шумовой гейт, автоматическая
регулировка усиления (AGC), компрессор и брикволл-лимитер, с автоматической
15-секундной 3-этапной калибровкой, готовыми пресетами, самопрослушиванием
и выводом обработанного сигнала на виртуальное аудиоустройство для
использования в Discord/Zoom/OBS/любом другом приложении.

## Как получить готовый .exe без установки Visual Studio

Этот код был написан без доступа к Windows и без возможности обратиться к
NuGet — поэтому здесь нет заранее скомпилированного .exe: скомпилировать
WPF-приложение можно только на Windows, а не в среде, где готовился этот
проект. Есть два способа получить рабочий .exe:

### Способ A — GitHub Actions (не требует установки Visual Studio)

1. Создайте пустой репозиторий на github.com и загрузите в него содержимое
   этой папки целиком (включая скрытую папку `.github`).
2. Откройте вкладку **Actions** репозитория. Сборка запустится автоматически
   при загрузке (или запустите её вручную: Actions → "Build NeuroMicrophone"
   → "Run workflow").
3. Дождитесь зелёной галочки (обычно 3–5 минут). GitHub бесплатно предоставляет
   для этого настоящую виртуальную машину с Windows — там проект по-настоящему
   компилируется и прогоняются юнит-тесты.
4. В конце открывшейся страницы запуска будут файлы для скачивания:
   - **NeuroMicrophone-app** — папка с готовой программой (просто запустить
     `NeuroMicrophone.exe` внутри);
   - **NeuroMicrophone-Setup** — собранный установщик `NeuroMicrophone_Setup.exe`
     (появится, только если вы предварительно положили подписанный пакет
     драйвера в `Installer/Driver/Package/`, см. ниже).

Это самый простой путь: не нужно ничего ставить на свой компьютер, кроме
браузера и бесплатного аккаунта GitHub.

### Способ B — Visual Studio на своём компьютере

1. Установите Visual Studio 2022 Community (бесплатно) с нагрузкой ".NET
   desktop development", и .NET 8 SDK.
2. Откройте `src/NeuroMicrophone.csproj` (Файл → Открыть → Проект/Решение).
3. Дождитесь восстановления NuGet-пакетов, нажмите F5 — для разработки/отладки,
   либо ПКМ по проекту → "Publish" — чтобы получить готовый .exe.

> Код был подготовлен без возможности собрать его локально, поэтому первую
> сборку стоит сделать внимательно: если IntelliSense покажет расхождение в
> сигнатуре какого-то API (например, из-за более новой/старой версии пакета
> NAudio), поправьте по подсказке компилятора — способ A выше как раз
> компилирует и тестирует код на настоящей Windows-машине и сразу покажет,
> если что-то не так.

## Возможности

- **DSP-цепочка**: RNNoise (шумоподавление с учётом голосовой активности) →
  шумовой гейт → AGC → компрессор → брикволл-лимитер (-2 dBFS, всегда включён)
- **Автонастройка** — 15-секундная 3-этапная калибровка по фоновому шуму,
  обычной и громкой речи
- **Пресеты** — "Тихая комната", "Шумный опенспейс", "Стрим" — мгновенное
  применение вместо (или как отправная точка для) автонастройки
- **Расширенные настройки** — ручная тонкая подстройка порога гейта, силы
  шумоподавления, целевого уровня AGC, порога/коэффициента компрессора
- **Прослушать себя** — вывод обработанного сигнала на отдельное устройство
  (наушники/динамики), независимо от основного вывода на виртуальный кабель
- **Индикаторы Gain Reduction** — сколько прямо сейчас "срезают" компрессор и
  лимитер, отдельно от общего VU-метра с классическим peak-hold
- **Настройки сохраняются** между запусками (`%LocalAppData%\NeuroMicrophone\settings.json`)
- **Автозапуск с Windows** — переключатель в расширенных настройках
- **Заглушка микрофона** по Ctrl+Shift+M, сворачивание в трей
- **Установка/удаление виртуального драйвера** прямо из приложения

## RNNoise (шумоподавление)

Библиотека RNNoise (`https://github.com/xiph/rnnoise`, BSD-3-Clause)
поставляется в виде исходного кода на C, поэтому её нужно собрать один раз
(через MSYS2/MinGW — команды в предыдущей версии этого README в истории
проекта, либо любой другой способ сборки библиотеки под Windows x64) и
положить результат как `src/native/rnnoise.dll`. Если файла нет, приложение
не упадёт — просто отключится шумоподавление, вернётся вероятность голоса
(VAD) в 0, а остальная цепочка продолжит работать в полном объёме.

## Виртуальный аудиодрайвер

По требованиям безопасности Windows (Driver Signature Enforcement) любой
kernel-mode аудиодрайвер должен быть подписан действительным сертификатом —
это ограничение самой ОС, а не данного проекта. Два легитимных пути получить
такой пакет подробно описаны в `Installer/README_DRIVER.md`. Пока пакета нет,
приложением можно пользоваться с любым уже установленным виртуальным
аудиоустройством — выберите его в выпадающем списке "Виртуальный вывод".

Кнопки "Установить драйвер" / "Удалить драйвер" в приложении и логика в
`Installer/setup_script.iss` уже корректно обрабатывают "опубликованное" имя
INF (`oemNN.inf`), которое присваивает система — оно автоматически находится
через `pnputil /enum-drivers` и/или сохраняется при установке, так что
удаление драйвера работает надёжно даже спустя долгое время после установки.

## Тесты

`tests/NeuroMicrophone.Tests` — юнит-тесты на xUnit для чистой DSP-математики
(`LevelMeter`, `NoiseGate`, `AutoGainControl`, `Compressor`, `Limiter`),
включая проверки вида "лимитер никогда не превышает потолок" и "гейт с
высокой вероятностью VAD остаётся открытым даже на тихом сигнale". Запускаются
автоматически в GitHub Actions (способ A выше) или локально командой:

```
dotnet test tests/NeuroMicrophone.Tests/NeuroMicrophone.Tests.csproj
```

## Известные ограничения

- Разбор вывода `pnputil` (и в приложении, и в установщике) ориентируется на
  английские подписи "Published Name" / "Original Name" — на локализованных
  (не англоязычных) сборках Windows эти подписи могут отличаться.
- Ресемплинг реализован через `WdlResamplingSampleProvider` из NAudio; при
  необходимости более точного контроля качества можно заменить на
  собственный полифазный ресемплер.
